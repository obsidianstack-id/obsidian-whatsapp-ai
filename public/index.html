API Provider Top Up

Tambahkan dan atur provider dari panel tanpa mengubah kode. Impor katalog memakai format JSON provider yang dikonfigurasi di bawah.

Pilihan cepat tersedia untuk APIGames.id, Melostore H2H, Distusi, Gofaz, Pasargamer.com, atau provider custom. Setiap provider memiliki format API sendiri; isi endpoint, autentikasi, dan pemetaan katalog dari dokumentasi resmi provider.
Daftar provider akan dimuat saat panel dibuka.
